Z.Engine
How Z.Engine works
It shows live results from Wikipedia and Wikimedia Commons, a dictionary and a calculator, and live Google web results once you add a free Google Programmable Search key. Full web results open on Google, DuckDuckGo, Bing and Brave. Type a web address to open the site.
Google Programmable Search key
1) Create a search engine that searches the entire web at programmablesearchengine.google.com and copy its Search engine ID (cx). 2) Create an API key in Google Cloud with the Custom Search API enabled. The free tier gives about 100 searches a day. Keys are saved only in this browser.
